EDUTECH CHILE

Descripción: EduTech Chile es un portal informativo dirigido a la comunidad escolar. Su objetivo es compartir información educativa, cursos y novedades relacionadas con la tecnología. 

Tecnologías utilizadas: HTML5, CSS3, Python, Git y GitHub Pages. 

Estructura del proyecto: index.html página principal, styles/style.css diseño y estilos, scripts/generador.py que genera automáticamente las novedades, novedades.html página generada mediante Python, TESTING.md bitácora de pruebas, README.md documentación del proyecto, assets para imágenes. 

Ejecución del proyecto: abrir el proyecto en Visual Studio Code, abrir la terminal, ejecutar el comando Python scripts/generador.py, abrir index.html en el navegador. 

Publicación: el proyecto se publicará mediante GitHub Pages.
